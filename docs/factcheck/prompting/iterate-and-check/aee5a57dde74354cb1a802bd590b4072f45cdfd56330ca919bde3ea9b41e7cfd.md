## Emanuel's take, in full

> My rule for prompts is short. **Start simple. Then watch.** Ask for one thing and read what comes back. Change one thing and read again.

> I treat a first answer like a first sketch. A sketch is there to be corrected. Then I run the same prompt again, and the answer changes. Is that a fault? No. It's information. It tells me how much weight one answer can carry.

> And when a fact matters, I don't ask the same tool to check itself. I go to the source. None of this is clever, only patient. **Humility is a method**: try, observe, admit the limits, adjust.
