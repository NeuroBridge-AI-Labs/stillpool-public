## Emanuel's take, in full

> An agent takes steps for you. It searches, uses a tool, checks and goes again. That's useful, and it changes my job. I picture a boat. The agent can row. A person holds the rudder.

> The rudder is the direction, and the direction comes from values. So I decide what it may touch. I decide what it must never do. I decide when it stops and asks me.

> And if it does harm, who answers? I do, the person who sent it. Never the software. **We set the values and the direction.** A tool can carry out a task. **Only a person can answer for it.**
